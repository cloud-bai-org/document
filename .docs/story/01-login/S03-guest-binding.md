# S03: 訪客儀式完成後詢問登入 <!-- #7 -->

**Journey**: login
**Labels**: priority:medium
**Story Dependencies**: S01, S02
**Sub-tasks**:
- [ ] FE: 完成摘要頁登入提示 UI <!-- #8 -->
- [ ] BE: 訪客紀錄綁定至帳號 <!-- #9 -->

## UX 操作流程

1. 訪客完成一次儀式，進入完成摘要頁
2. 摘要頁底部顯示「是否登入以保存紀錄？」+「登入」「稍後再說」
3. 點「登入」→ 進入 `/login`，登入後本機紀錄綁定至帳號
4. 點「稍後再說」→ 關閉提示，紀錄保留於本機，當天不再彈出

## UI 元件規格（Frontend）

- `LoginPromptCard`：摘要頁底部卡片
- 文案：「想保留這次的紀錄嗎？登入後就能跨裝置同步。」
- 「稍後再說」記住選擇，當天不再提示

## 後端職責（Backend）

- 接收本機訪客紀錄並綁定到當前登入帳號
- 處理綁定失敗的情境（不能讓本機紀錄遺失）

## Acceptance Criteria

```gherkin
Scenario: 完成摘要頁顯示登入提示
  Given 訪客剛完成一次儀式
  When 進入完成摘要頁
  Then 頁面底部顯示登入提示卡片

Scenario: 點稍後再說當天不再提示
  Given 完成摘要頁顯示登入提示卡片
  When 使用者點「稍後再說」
  Then 提示卡片關閉
  And 當天再次完成儀式不再顯示登入提示

Scenario: 登入後綁定本機紀錄
  Given 完成摘要頁顯示登入提示卡片
  When 使用者點「登入」並完成登入流程
  Then 本機訪客紀錄綁定至該帳號
  And 在其他裝置以同一帳號登入可看到此紀錄

Scenario: 綁定失敗不遺失本機紀錄
  Given 使用者完成登入並嘗試綁定
  When 綁定流程因網路或後端錯誤失敗
  Then 本機訪客紀錄保留
  And 系統顯示重試提示
```

## Test Cases

- TC-1: 點登入完成綁定
- TC-2: 點稍後再說，當天不再提示
- TC-3: 既有帳號登入 → 本機紀錄合併至帳號
- TC-4: 綁定失敗 → 本機紀錄保留

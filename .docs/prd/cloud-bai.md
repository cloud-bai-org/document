# Cloud Bai 雲端拜拜 — 產品需求文件 (PRD)

> 版本：v0.1
> 狀態：草稿

## 願景

打造一個融合台灣民間信仰文化的線上拜拜平台，讓使用者無論身在何處，皆能以數位化方式完成莊嚴而完整的拜拜儀式。透過降低實體焚燒帶來的環境負擔，讓信仰與環保並行，並以視覺化的環保成效持續強化使用者的價值感。

## 問題與動機

- **空間限制**：在外地工作或居住的使用者，無法經常返鄉參拜或祭祖
- **環境負擔**：傳統焚香、燒金紙、燒紙紮造成空氣污染與紙張消耗
- **儀式完整性缺口**：現有線上方案多止於單一動作（如電子點香），缺乏完整流程
- **遠端共拜需求**：祭祖原為家族共同活動，但家人分散各地，難以同時參與
- **文化推廣**：日韓與英語系使用者對台灣宮廟文化有興趣，但語言門檻高

## 目標使用者

- **主要使用者**：在外地或國外、無法常返鄉的台灣人（25–50 歲）
- **次要使用者**：希望以更環保方式拜拜的本地使用者；想透過 App 凝聚家族祭祖儀式的家庭
- **延伸使用者**：對台灣民間信仰文化感興趣的日、韓、英語系使用者

## 價值主張

- **儀式完整**：從選擇祭拜對象到擲筊、燒金紙、燒紙紮，完整覆蓋兩種模式（拜神明 / 祭祖）
- **體驗莊嚴**：以「廟宇深色莊嚴風格」與物理動畫，重現實體儀式的氛圍與節奏
- **環保有感**：每次儀式量化呈現節省的紙張與碳排，累積里程碑激勵
- **不打擾的計時**：焚香於背景進行，使用者可立即繼續儀式並接收完成通知
- **家族共拜**：透過 PIN 碼建立房間，遠端家人在各自裝置完成個別操作，主持人統籌流程
- **零門檻啟用**：訪客模式免登入即可體驗完整儀式

## 範圍與能力概覽

本產品由 14 個 capability 組成，分為四個層級：

### 1. 核心儀式體驗（拜拜流程）

- **worship-ceremony**：儀式流程引擎，涵蓋拜神明與祭祖兩條路徑，含步驟引導、進度恢復、完成摘要
- **offering-arrangement**：供品準備與擺設，包含虛擬供品拖放與實體供品拍照
- **incense-simulation**：焚香動畫與非阻塞背景計時、推播通知
- **joss-paper-burning**：金紙種類選擇與焚燒模擬（自動 / 手動投入）
- **paper-craft-burning**：祭祖專屬的紙紮物品焚燒
- **divination-blocks**：擲筊物理動畫與結果判定

### 2. 延伸功能（連結實體與長期價值）

- **temple-checkin**：實體廟宇 QR 掃描打卡、祈願目的選擇、參拜路線導覽、足跡地圖與徽章
- **group-worship**：多人遠端共拜房間（僅祭祖），含主持人控制、即時同步、斷線處理
- **eco-impact-tracker**：單次與累積環保成效計算、視覺化、里程碑激勵

### 3. 跨領域服務

- **user-auth**：訪客模式 + Google / LINE / Facebook 第三方登入、登入後同步、登出
- **i18n**：繁中、英、日、韓四語系，含 UI 文案與文化內容在地化

### 4. 基礎平台與資產

- **app-platform**：Mobile-First 響應式、觸控無障礙、應用資訊架構
- **design-system**：莊嚴深色設計原則、色彩語彙（絳紅 / 琉璃金 / 蒼綠 / 玄黑 / 香灰白）、字體排版
- **domain-model**：核心領域實體（廟宇 / 神明 / 供品 / 金紙 / 紙紮 / 祈願目的），含環保計算屬性

## 成功指標

- **體驗完成率**：開啟「拜神明」流程的使用者，完成至摘要頁的比率
- **背景計時黏著度**：背景焚香完成通知的點擊回流率
- **登入轉換率**：訪客完成儀式後完成第三方登入綁定的比率
- **多人房間採用**：祭祖場次中，多人模式佔比與每場平均成員數
- **環保里程碑達成**：使用者累積至首個里程碑的中位時間
- **i18n 觸及**：非繁中介面語言使用者佔比與留存

## Non-Goals

- 不做社群分享、貼文、評論等社交網絡功能
- 不與外部環保認證組織合作或排行榜
- 不販售實體商品（金紙、供品、紙紮等）
- 不販售或推廣特定宮廟（所有廟宇名稱 MUST 為虛構）
- 不取代實體信仰儀式或宗教法事服務

## 詞彙表

| 詞彙 | 說明 |
| --- | --- |
| 拜神明模式 | 對神明祭拜的儀式流程，含掃廟、選神明、擺供品、焚香、祈禱、擲筊、燒金紙 |
| 祭祖模式 | 對祖先/親人祭拜的儀式流程，含稱謂、地點、實體供品、焚香、祈禱、燒金紙、燒紙紮 |
| 焚香非阻塞 | 點香後計時於背景進行，使用者可立即進入下一步而非乾等 |
| 聖筊 / 笑筊 / 陰筊 | 擲筊結果：一正一反 / 兩面朝上 / 兩面朝下 |
| 主持人 | 多人房間建立者，具控制流程與共用設定權限 |
| 訪客模式 | 免登入體驗，紀錄保存於本機並以匿名身分上傳至雲端 |
| 環保成效 | 線上儀式相較實體儀式減少的紙張（公克）與碳排（公克 CO₂） |
